# Glossaire français → anglais

Toutes les traductions (interface, cours, exercices, fiches) emploient ces mots, pour que
l'anglais reste cohérent d'un écran à l'autre. Le ton anglais suit docs/STYLE.md : des phrases
claires et liées, sans remplissage, en tutoyant le lecteur par « you », sans exclamation.

## Ce qu'on ne traduit pas

Les noms propres et les noms de fonctions ou de registres restent tels quels : `Cconws`, `Pterm0`,
`Supexec`, `OpenLibrary`, `DMACON`, `COLOR00`, `BPLCON0`, `WRT_MODE`, Devpac, MONST, Hatari,
WinUAE, EmuTOS, AROS. Les chaînes affichées par les programmes (`DC.B 'Bonjour'`) restent aussi
en français : seul le texte des commentaires change dans le code.
