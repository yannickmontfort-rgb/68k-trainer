## Le registre d'état

Le registre d'état, SR, fait 16 bits. Son octet du bas, le CCR, contient cinq drapeaux (*flags*).
Le 68000 les met à jour après la plupart des instructions. Au chapitre suivant, les branchements
s'en serviront pour décider.

| Flag | Vaut 1 quand… |
|---|---|
| N | le résultat est négatif (bit de poids fort à 1) |
| Z | le résultat est nul |
| V | le résultat signé est faux, comme 127 + 1 en `.B` |
| C | le résultat non signé est faux : retenue ou emprunt |
| X | copie de C, pour calculer sur plusieurs mots |

Toutes les instructions ne touchent pas tous les flags :

- `MOVE`, `CLR`, `TST`, `AND`, `OR` : N et Z suivant le résultat, V et C à 0, X inchangé ;
- `ADD`, `SUB`, `NEG` : les cinq ;
- `MOVEA`, `LEA`, `ADDA`, `SUBA` : aucun.

Dans le pas à pas, un flag à 1 apparaît en bleu.

## L'octet du haut

Pour l'instant, un seul bit compte : S (bit 13). À 1, le processeur est en mode superviseur ; à 0,
en mode utilisateur.

:::atari
Le TOS lance les programmes en mode utilisateur. Dans les trois premiers chapitres, 68k Trainer les
lance en superviseur, pour simplifier. On y reviendra avec le TOS.
:::
:::amiga
AmigaOS lance les programmes en mode utilisateur, et 68k Trainer aussi. Sur l'Amiga 500, cela
n'interdit que quelques instructions, comme `MOVE` vers SR, `STOP` ou `RTE`.
:::

Les autres bits viendront plus tard, avec les interruptions et le débogage.
