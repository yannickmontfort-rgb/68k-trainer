## Le registre d'état

Le registre d'état, SR, est un registre de 16 bits qui décrit l'état du processeur. Son octet du
bas, le CCR, contient cinq drapeaux (*flags*) que le 68000 met à jour après la plupart des
instructions pour résumer le résultat ; au chapitre suivant, les branchements s'en serviront pour
prendre leurs décisions.

| Flag | Vaut 1 quand… |
|---|---|
| N | le résultat est négatif (bit de poids fort à 1) |
| Z | le résultat est nul |
| V | le résultat signé est faux, comme 127 + 1 en `.B` |
| C | le résultat non signé est faux : retenue ou emprunt |
| X | copie de C, pour calculer sur plusieurs mots |

Toutes les instructions ne modifient pas tous les flags :

- `MOVE`, `CLR`, `TST`, `AND`, `OR` mettent N et Z suivant le résultat, V et C à 0, et laissent X ;
- `ADD`, `SUB`, `NEG` modifient les cinq ;
- `MOVEA`, `LEA`, `ADDA`, `SUBA` n'en modifient aucun.

Dans le pas à pas, un flag à 1 apparaît en bleu.

## L'octet du haut

Pour l'instant, un seul bit de l'octet du haut nous intéresse : le bit S (bit 13), qui place le
processeur en mode superviseur quand il vaut 1, et en mode utilisateur quand il vaut 0.

:::atari
Le TOS lance les programmes en mode utilisateur ; dans les trois premiers chapitres, 68k Trainer
les lance en superviseur pour simplifier, et l'on reviendra sur les deux modes avec le TOS.
:::
:::amiga
AmigaOS lance les programmes en mode utilisateur, et 68k Trainer fait de même. Sur l'Amiga 500, ce
mode n'interdit que quelques instructions, comme `MOVE` vers SR, `STOP` ou `RTE`.
:::

Les autres bits viendront plus tard, avec les interruptions et le débogage.
